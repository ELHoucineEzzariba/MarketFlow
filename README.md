# MarketFlow – Clickable Two-Sided Marketplace Mockup

## Included
- Public marketplace landing page
- Search and category filtering
- Customer dashboard
- Provider dashboard
- Admin dashboard
- Replaceable module manager
- WhatsApp integration via wa.me links
- Email integration via mailto links
- Messaging, quote and request modals
- Dark/light mode
- Responsive layout

## Open the demo
Open `index.html` in any modern browser.

## Demo roles
Inside the dashboard, switch between:
- Customer
- Provider
- Admin

## Notes
This is a static front-end concept designed to show the client how the final marketplace could work. Real authentication, database, payment processing, email APIs and WhatsApp Business API would be connected during development.
